Chapter Nine, Section Eight

A Basic Grading Workflow, Start to Finish

Part IX of XVI
Category Practical
Sheet 059 / 095
Depends On 9.7
Read Time ~7 Min

Nothing in this closing chapter is new. Every tool it uses was introduced somewhere earlier in Part IX. What this chapter does instead is assembly: taking scopes, the node graph, primary correction, secondary correction, matching, and delivery, and walking them in the order a real project actually calls for them, on one pass, from an untouched timeline to a finished, delivered grade.

Step One — Confirm Color Management Before Anything Else

Before a single wheel gets touched, confirm the project's color management is configured correctly — the input transform Chapter 9.7 described, translating whatever the cameras recorded into a proper working space. Grading on top of a misconfigured translation means every decision that follows is a decision made against a wrong picture, exactly as Chapter 1.4 warned back in Chapter One. This check takes a minute and it happens first, every time, with no exceptions.

Step Two — Establish the Node Structure

With the image trustworthy, set up the node structure from Chapter 9.3 before making any actual adjustments: a first node reserved for primary correction, room left for a parallel branch if secondary work turns out to be needed, and nodes labeled for what they'll do rather than left as generic numbers. Deciding the shape of the graph before filling it in keeps the session organized from the first adjustment onward, rather than retrofitting structure onto a tangle later.

Step Three — Primary Pass, Scopes Open

In that first node, set Lift, Gamma, and Gain from Chapter 9.4 with the waveform open, establishing clean black and white points and an overall color balance that reads correctly against the scopes, not just against the monitor. This is the broad, whole-frame pass — get it right here, and everything downstream has a solid floor to build on.

Step Four — Match to the Scene's Anchor

Before any creative decisions get made, apply Chapter 9.6's matching process: pick the scene's anchor shot, and bring every other shot in the scene into agreement with it using the primary correction just established, comparing scope readings rather than impressions. A scene that doesn't match yet isn't ready for a look — it's still a correction problem, and Chapter 9.1 already covered why solving the wrong one first doesn't hold up.

Step Five — Secondary Refinement and the Creative Look

Only once a scene is internally consistent does secondary correction from Chapter 9.5 come in — qualifiers and power windows addressing whatever a matched, primary-corrected image still needs isolated: a face that needs a touch more warmth, a sky that needs more separation from the midtones beneath it. This is also where a creative LUT or a deliberate stylistic push belongs, from Chapter 9.7 — applied to footage that's already earned it by matching cleanly, not as a substitute for the steps before it.

Grading isn't a single sweep across a timeline. It's this specific order, correction before look and matching before style, each step depending on the one before it actually being finished — which is the same lesson this whole part has been building toward, one chapter at a time.

Step Six — Confirm Delivery Space and Render

Last, before rendering, run Chapter 9.7's final check: color management still configured as it was throughout the session, any LUT sitting deliberately on top of already-matched footage, and the output color space matching exactly where the file is actually going. A grade that passes every earlier step still ships wrong if this last one is skipped, which is precisely why it's the step this workflow ends on rather than an afterthought handled separately at delivery time.

That completes Part IX. Between understanding what grading actually does, reading scopes instead of guessing, building a grade as a legible node graph, correcting the whole frame and then just the part that needs it, matching shots into invisibility, and getting a LUT and a color space to cooperate rather than undo each other, the full arc of a Resolve grade is covered start to finish. Part X turns from color to a different kind of image work entirely — compositing on the Fusion page, the same node-graph thinking Chapter 1.3 introduced and this part put to use, applied now to building an image out of separate visual elements rather than correcting one that already exists.

Key Concepts to Remember

  • A grading pass runs in a fixed order: color management, node structure, primary correction, matching, secondary refinement and look, then delivery.
  • Matching happens before creative work — a scene that doesn't agree with itself isn't ready for a look, only for more correction.
  • Every step in this workflow depends on the one before it actually being finished, not just started.
  • Confirming color management and output color space is the last step, not an afterthought — skipping it can undo every decision made earlier in the session.
