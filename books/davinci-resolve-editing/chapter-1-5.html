Chapter One, Section Five

Reading the Interface Without Getting Lost

Part I of XVI
Category Practical
Sheet 005 / 095
Depends On 1.2
Read Time ~7 Min

Seven pages, each with its own tools, sounds like seven interfaces to memorize. It isn't. Resolve reuses the same handful of interface conventions on every page, which means the effort you spend learning the layout of one page mostly transfers to the rest. This chapter is a short, practical map of those recurring conventions — not a tour of every button, but the underlying grammar that lets you look at any page for the first time and already have a rough idea what you're looking at.

The Page Switcher Is Always in the Same Place

Along the bottom of the window sits the row of page names from Chapter 1.2 — Media, Cut, Edit, Fusion, Color, Fairlight, Deliver. This bar never moves and never changes regardless of what page you're on, and it's worth treating it as home base. If you ever feel lost inside a page's tools, the fastest reset is simply looking down at that bar and confirming which page you're actually in — a surprising number of "why isn't this tool here" moments are actually "I'm on a different page than I thought."

Viewers: Your Window Into the Image

Every page gives you at least one viewer — a video preview window showing you the actual image, wherever your playhead or selection currently is. Some pages give you two: the Edit page splits into a Source viewer, showing a clip from the Media Pool before it's placed on the timeline, and a Timeline viewer, showing the sequence as built. Getting comfortable distinguishing "what am I looking at, the source or the timeline" early prevents a specific, common beginner mistake — editing changes into what you thought was the timeline when you were actually still looking at an unplaced source clip.

The single most useful habit for staying oriented in Resolve is asking two questions before you touch anything: which page am I on, and which viewer — source or timeline — am I actually looking at?

The Toolbar: Context-Specific, But Predictably Placed

Most pages carry a toolbar of some kind — a row of icons for the primary actions available on that page. On Edit, this is the trim and editing tools covered in Chapter 4.3. On Color, it's largely replaced by the node graph and a different control set entirely. The tools themselves change page to page because the jobs change page to page, but the location — usually along the top of the working area — stays consistent enough that you'll develop a reflex for where to look, even on a page you're using for the first time.

Inspector and Detail Panels: Selection-Driven

Across nearly every page, selecting something — a clip, a node, a track, a mixer channel — reveals a detail panel showing properties and controls specific to that selection. This is one of the most consistent ideas in the whole interface: nothing shows you everything at once. Instead, you select an object, and the relevant controls for that object appear. This keeps each page from being visually overwhelming, but it also means that if a control you expect to see isn't visible, the fix is very often "select the thing that control belongs to" rather than "hunt through menus."

The Media Pool and Bins, Visible Almost Everywhere

Your organized footage — the bins and clips you set up on the Media page, covered in Part II — remains visible and accessible from most other pages too, usually in a panel you can show or collapse. This is a direct expression of the "one shared project" idea from Chapter 1.2: you're not re-importing or re-locating footage as you move between pages. The same organized Media Pool travels with you from Edit to Color to Fairlight, because it's the same project the whole time.

A Practical Way to Learn a New Page Fast

When you land on an unfamiliar page for the first time, this short checklist will orient you faster than clicking around randomly: confirm which page you're on via the bottom bar; locate the viewer and identify what it's currently showing; find the toolbar and note what its icons broadly relate to, without needing to know each one yet; select something — anything — and watch what appears in the detail panel. That sequence works on Cut, on Fusion, on Fairlight, on Color, because it's the same underlying grammar every time, just applied to different tools.

None of this replaces actually learning what each page's tools do — that's the job of the rest of this book, page by page. But walking in with this map already in your head means you'll spend your first sessions on each new page learning that page's actual job, instead of relearning how Resolve's interface works from scratch every time you switch tabs.

Key Concepts to Remember

  • The page-switcher bar at the bottom is fixed and constant — use it to confirm which page you're on whenever a tool seems to be missing.
  • Always know whether a viewer is showing the Source (an unplaced clip) or the Timeline (the actual sequence) — confusing the two is a common early mistake.
  • Detail panels are selection-driven across the whole app — if a control seems to be missing, select the object it belongs to first.
  • The Media Pool travels with you across pages because every page shares the same project — you never re-import footage to switch tools.
